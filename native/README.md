# Orbital Phone and TV previews

Download the signed APK for your device from the [native preview release](https://github.com/garrettwise16-crypto/orbital-for-jellyfin/releases/tag/native-v2026.10.27-preview.1). Install it, then enter your Jellyfin server address and sign in. These apps have their own public package identity and update channel.

Use Orbital Setup on the server to add the web interface, Sports and optional integrations. The Phone app uses your server's web interface alongside its native player. TV has its own native interface. Episode and season selection, start from beginning, short seeking, channels, Sports and free estimated trackers are included. Only the services/data you connect are available. Paid picture alignment and feed-trust implementations are excluded.

Every APK is accompanied by its complete corresponding source archive, including build instructions and original license notices. Phone is GPL-2.0; TV is GPL-2.0. The source archive is the source for that exact APK, not an unrelated upstream snapshot. Updates verify the public signer and downloaded file hash.

## Validation limits

Phone75: 547 tests in 50 suites. TV301: 1,521 tests in 192 suites. Both builds used frozen sources and passed full source/APK privacy checks. These public package identities have not yet completed physical installation acceptance against an independently configured server. Automated setup journeys use isolated server fixtures. The 5–8-second live-switching target has not been established; the TV Last channel control remains under investigation. This is a preview, not a claim of completed cross-client acceptance.
